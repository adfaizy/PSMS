PSMS Photos — GGES Ladheke Unchay
=================================

Folders match classes from the current school login.

Structure:
  Photos/
    ECE/
      1.jpg
      2.png
    Nursery/
      1.jpg
    Class 1/
      1.jpg
    Class 2/
      ...

Put each photo file named with the student roll number (any image format).

Import:
1. Examination → Student Record
2. Import photos (folder)
3. Select this Photos folder

If you add/remove classes in Settings, use "Create class folders" in Student Record
(or ask to regenerate this Photos tree for the logged-in school).
